# MyPrayer

## Research and notes vault

Store all research, sources, docs and references for this project as Markdown in the Obsidian vault at `H:\Documents\Obsidian\Vault\prayer-vault`, not in this repo:

- `source/`: external links and articles, with a one-line takeaway each.
- `refs/`: analysis and reference notes (competitors, inspiration, comparisons).
- `docs/`: project docs and status (decisions, open questions).

Give every note frontmatter (`tags`, `date` as YYYY-MM-DD) and link related notes with `[[note-name]]` wikilinks. Update an existing note rather than creating a duplicate.

Exception: `PRODUCT.md` and `DESIGN.md` stay in the repo root, because design tooling reads them from there.
